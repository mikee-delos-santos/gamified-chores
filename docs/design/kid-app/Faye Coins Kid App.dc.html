1Faye Coins — kid app in Modernist

What I read. The Expo app is still the starter shell (one home screen pinging /health), so there is no kid UI to match yet. Everything below is built on the MVP spec and schema: chores with reward_coins (decimal), an append-only coin_transactions ledger, child profiles with no login, admin-controlled peso rate.

Assumptions. Balance is always the ledger sum, never a stored number. Kids pick a profile instead of logging in. Peso value stays hidden until tapped, and lives in the Bank. Mixed ages, so every row is one tap, labels are short, and the reward is the loudest thing on screen. Deferred epics are mocked as real UI (coin bank, video proof, push).

Design system. Modernist: Archivo only, zero radius, 2px rules, one red. That reads unusually strict for a kids' app, so the play comes from scale and the red rather than from rounded, colourful decoration — coin amounts are set at poster size and the reward moment is a full-bleed red plate. Photography and video slots print grayscale.
